# CodeAlpha_Music_Generation_with_AI

An advanced, full-screen desktop AI Music Composer Dashboard built as part of the CodeAlpha Artificial Intelligence Internship program. This application leverages a Recurrent Pattern Matrix Engine (Markov-chain based sequence processing) to predict, stream, and visually synthesize live musical tracks directly within a desktop web browser.

## 🎵 Features
* **Ultra-Wide Desktop UI:** Optimized layout that stretches beautifully across full monitor displays for a premium dashboard experience.
* **Interactive Engine Configurations:** Softmax Temperature (creativity scale) and composition length adjustment sliders to seamlessly manipulate probabilistic text-to-music generation patterns.
* **Live Audio Synthesizer:** Converts generated algorithmic musical sequences into pure sine wave audio signals natively playable inside the browser.
* **Visual Piano Synthesizer Output:** An interactive, illuminated virtual piano keyboard component that dynamically highlights active sequence keys during compilation.
* **MIDI Track Export:** Includes an instant file generation engine to download and save your AI compositions as physical `.mid` audio files.

## 🛠️ Tech Stack
* **Language:** Python 3.10+
* **Framework:** Streamlit (Web UI)
* **Mathematical Utilities:** NumPy
* **Music Representation:** Music21
